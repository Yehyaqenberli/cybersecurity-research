# Security Policy

## About This Repository

This repository contains **anonymized, public case studies** from independent security research conducted under responsible disclosure principles. It does **not** contain:

- Working exploits, payloads, or reproduction steps
- Company names, domains, IP addresses, or infrastructure details
- Credentials, API keys, tokens, private keys, or secrets
- Customer PII or financial data
- Enough detail to reconstruct the identity of any assessed target

## Reporting a Concern

If you believe any content in this repository inadvertently discloses sensitive information — a company identity, a credential, a domain, or any detail that could enable an attack — please report it immediately:

- **Email:** [use GitHub's private vulnerability reporting for this repository]
- **Response time:** I will review and respond within 48 hours.
- **Action:** If a disclosure is confirmed, the affected content will be removed or further redacted immediately.

## Responsible Disclosure

If you are a representative of an organization referenced in these case studies and wish to discuss the content, please contact me directly. I am committed to working with affected parties and will remove or modify content upon reasonable request.

## No Exploitation Guidance

This repository is intended to demonstrate security research methodology, responsible disclosure practices, and security engineering lessons. It is explicitly **not** intended as a guide for unauthorized access or exploitation. No content here should be used to attack any system without explicit, written authorization from the system owner.
